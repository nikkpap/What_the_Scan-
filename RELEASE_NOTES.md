## What the Scan?! v1.0.1 — first release

**Downloads**
- **Windows:** `WhatTheScan-windows-x64.exe`. Double-click it. Windows may show "Windows protected your PC" because the file is not signed yet: click *More info › Run anyway*.
- **Linux:** `WhatTheScan-linux-x64`. Run `chmod +x WhatTheScan-linux-x64`, then open it.
- **macOS / any OS with Python 3:** `WhatTheScan.pyw`. It installs its own dependencies on first start.

The first start installs the NAPS2 scanning engine automatically, if it is missing.

**Features**
- Scan to PDF, JPG or PDF + JPG, plus an optional editable Word (.docx) or OpenDocument (.odt) file.
- Finds Epson, Canon and HP scanners on every driver at the same time.
- Status light (green / yellow / red), with a "scanner in use" warning shared between PCs.
- OCR with automatic or manual languages, downloaded automatically.
- Translation with Google Translate, MyMemory or LibreTranslate.
- English / Greek interface, auto / light / dark theme.
- Over-the-air updates from GitHub releases.

**Ελληνικά**
- **Windows:** κατέβασε το `.exe`. Αν εμφανιστεί «Τα Windows προστάτευσαν τον υπολογιστή σας», πάτα *Περισσότερες πληροφορίες › Εκτέλεση οπωσδήποτε*.
- **Linux:** κατέβασε το `WhatTheScan-linux-x64`, δώσε `chmod +x` και άνοιξέ το.
